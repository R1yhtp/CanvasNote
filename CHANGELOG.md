# Changelog

## 0.1.0 — First public release

- Blank infinite canvas with drawing, notes, text, images, shapes, and PDF page import.
- Undo and redo inside the drawing toolbar.
- Collapsible toolbar with bottom, left, and right positions; device layout preferences persist.
- Pen settings in a dismissible popover; directly accessible eraser and undoable clear.
- Local automatic saving, editable project files with bundled assets, and PNG export.
- Optional themes, custom backgrounds, and presentation regions.
- Windows portable packaging, web build, bilingual documentation, and CI checks.

Earlier 0.2.x packages were private development previews. 0.1.0 begins the public release series; the project-file format remains version 1.
